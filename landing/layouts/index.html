01 / THE ROUTE

Your command.
Your call.

Set an environment variable to choose where python3 goes. The alias forwards every argument and returns the child interpreter's exit status.

01

Choose a virtual environment

PYTHON3_ALIAS_VENV runs the venv interpreter and sets its child environment.

HIGHEST PRIORITY
02

Choose a Python executable

PYTHON3_ALIAS_PYTHON points to a specific interpreter path.

03

Choose a version

PYTHON3_ALIAS_VERSION uses the Windows py launcher when available, or a versioned executable on PATH.

04

Set nothing

The alias uses the Python interpreter that launched it.

02 / INSTALL

A path for the
missing command.

Install with pipx for an isolated command on your path. For a particular interpreter, install the wheel into a dedicated virtual environment with pip.

Installation details ↗
Git Bash / Windows
# Isolated command on your PATH
pipx install python3-alias

# Send this invocation to Python 3.14
PYTHON3_ALIAS_VERSION=3.14 python3 -V

# Or use a local virtual environment
PYTHON3_ALIAS_VENV=./.venv python3 -m pip list

03 / WHY IT EXISTS

That Makefile line should just work.

Some tools assume python3 is available, even on systems where the executable is named python. This tiny alias gives that command an intentional destination.

MakefilePLATFORM_ARCH := $(shell python3 -c "import platform; print(platform.machine())")

The package does not install Python or replace system launchers. uv reserves the python3 script name; install this package with pip or pipx in an isolated environment.
